# 知岸 · 每一步，都算数

面向公考备考的学习工作台，提供网页与 uni-app 微信小程序。Vue 3 + TypeScript 前端，FastAPI 模块化后端，SQLite 持久化；v0.3 在账户隔离、备份恢复与同步基础上增加小程序端，沿用同一账号与学习数据。

## 已实现

- 今日概览：真实学习时长、自动打卡、连续学习天数、到期复习、最近 7 天客观题正确率。
- 学习计划：按周查看，新增、调整、删除，区分当天计划、所有待办与已完成任务。完成时填写实际学习记录。
- 学习记录：创建、编辑、删除和补记；按日期、科目、关键词筛选；申论与主观题单独记录作答和反馈。
- 专注计时：开始、暂停、继续、结束后保存；同一浏览器刷新后保留，并同步其他标签页的计时状态。
- 复习卡片：内容、笔记、来源、到期日；先回忆后揭示笔记；按记忆反馈调整间隔；保留复习历史，支持归档与恢复。
- 数据复盘：7 / 30 天学习趋势、各科目时间分配、正确题数与题量、计划完成率、未来一周复习安排。
- 目标与设置：自定义称呼、考试名称、考试日期、每日目标、自定义科目。
- 数据导出：全部业务数据导出 JSON；学习记录导出带 UTF-8 BOM 的 CSV，兼容 Excel。
- 备份恢复：兼容 v0.1 JSON；数量预览、重复与冲突检测、合并新增 / 完整替换、恢复前自动备份、历史下载与回退。
- 账户：注册 / 登录 / 退出 / 修改密码；首个账户保留本机现有数据；账户之间隔离记录、导出、备份与浏览器计时。
- 同步：保存到同一个服务后，页面每 30 秒刷新；回到页面或手动同步立即读取最新数据，跨页面登录切换会清除原账户显示。
- 小程序：今日、计划、复习、统计、我的五个主页面，支持记录、专注计时、账号密码登录与微信绑定接口。已生成可导入微信开发者工具的构建包；真实微信登录与发布尚待自己的 AppID、HTTPS 服务及真机验证。

首次运行只创建默认科目，不写入虚构的学习、打卡或考试日期。

## 启动

需要 Node.js 22.12+（或 24+）和 Python 3.11+。在 Windows 双击 `start.cmd`，或在本目录执行：

```powershell
.\start.ps1
```

首次启动会安装依赖并构建页面。打开 <http://127.0.0.1:8765>；窗口保持运行，Ctrl+C 停止。已构建时可用 `.\start.ps1 -SkipBuild` 快速启动。

`requirements-lock.txt` 固定了本次已验证的 Python 依赖版本；`requirements.txt` 保留直接依赖范围。

默认仅监听 127.0.0.1。未启用账户时，可以在本机直接使用；在“我的目标与设置 → 账户与同步”创建首个账户后，现有记录会保留，后续访问需要登录。默认关闭额外账户注册；需要多人使用时由服务配置开启。

手机跨设备使用需要访问同一个可达的服务地址。HTTPS 部署配置与搬迁步骤见 [部署说明](deploy/README.md)。小程序启动、构建和微信接入见 [小程序说明](miniapp/README.md)，注册、备案、隐私政策和审核准备见 [微信资料包](publish/wechat/README.md)。当前交付没有发布公网网站或微信正式版，也没有开通订阅消息。

已构建小程序 H5 产物时，本地服务同时提供 <http://127.0.0.1:8765/mini/> 手机界面预览。使用与网页相同的知岸账号登录；预览保存的内容会进入当前服务的真实数据库。

## 开发

```powershell
# 终端 1：后端
.\.venv\Scripts\python.exe -m uvicorn server.main:app --host 127.0.0.1 --port 8765 --reload

# 终端 2：前端，/api 自动代理到后端
npm run dev
```

前端开发地址为 <http://127.0.0.1:5173>，后端 API 文档在 <http://127.0.0.1:8765/api/docs>。

## 数据与架构

```text
src/                  Vue 页面、业务交互与可复用组件
miniapp/              uni-app 小程序、H5 预览与独立构建配置
server/database.py    数据表、数据库连接与默认时区
server/schemas.py     请求校验
server/services.py    学习聚合、打卡与复习间隔
server/auth.py        账户、密码散列、会话与请求保护
server/mini_auth.py   小程序令牌、微信 code 交换与绑定
server/backups.py     备份校验、预览、事务恢复与快照
server/migrations.py  旧数据库升级与升级前备份
server/config.py      环境配置
server/main.py        API 与生产环境静态文件服务
tests/                API 集成测试，使用隔离的临时数据库
data/zhian.db         个人数据，首次启动自动创建
data/backups/         升级和恢复前的自动备份
deploy/               Docker Compose 与 Caddy HTTPS 配置
```

计划与实际学习记录分别保存；复习项与每次复习历史分别保存。复习完成与学习时长入账在同一数据库事务中，重复提交不会重复计时。卡片版本校验防止旧页面重复更新排期。

学习日期默认使用 `Asia/Shanghai`（UTC+8），可设置 `ZHIAN_TIMEZONE` 环境变量。打卡按所选学习日期计算，同一天多条记录只算一天；今天尚未开始时，连续天数可延续到昨天。删除或调整记录会重新计算相关统计。删除计划会保留学习记录；删除复习产生的学习记录不会撤销已经完成的复习排期。

专注计时按账户存于当前浏览器的 localStorage，保存后才计入数据库。退出登录会暂停计时，重新登录原账户可以继续。持续计时最多 24 小时；跨午夜的计时默认归入开始日期，保存时应核对真实日期与时长。数据记录存在运行后端的数据库，与清理浏览器缓存无关。

数据库默认 SQLite。所有业务表以账户和记录编号共同标识数据，关联关系也校验账户归属。密码使用 PBKDF2-SHA256 加随机盐，服务端只保存随机会话令牌的散列；Cookie 使用 HttpOnly / SameSite，写入校验 CSRF 与当前账户。部署到 HTTPS 时开启 Secure Cookie，并设置允许的域名和来源。

小程序使用独立 Bearer 令牌和同一账户的数据归属校验，不能与网页 Cookie 互换。微信 AppSecret 只保存在后端环境；绑定已有账号必须验证密码，后端不保存或返回微信 session_key。小程序未保存的计时按服务与账号保存在当前设备，保存后才同步。

环境变量见 `.env.example`，由启动环境设置，应用本身不自动读取 `.env`。连接层兼容 PostgreSQL，但本版实机验证使用 SQLite。生产部署和同步边界见 [部署说明](deploy/README.md)。

## 备份与版本升级

在设置中打开“导入与恢复”，选择 10 MB 以内的知岸 JSON 文件。默认合并新增记录，保留当前目标及同编号冲突内容；完整替换需要核对预览并勾选确认。引用缺失、重复编号、非法题量或复习历史不一致会阻止导入。合并后的关联不兼容时，也会提示重新处理备份或选择完整替换。

预览有效期 10 分钟。预览后新增或修改了学习数据，需要重新预览。恢复前会先写入完整自动备份；校验、备份或数据库写入失败不会留下部分恢复结果。重复提交同一预览只执行一次。自动备份历史显示最近 100 份，可下载或再次预览恢复；服务端不会自动删除更早的文件。

首次从 v0.1 启动 v0.2 会自动迁移数据表，并先产生 `before-upgrade` JSON 快照。学习数据恢复不会修改登录账户、密码、会话或已有备份。正式升级前停止旧服务，让新服务独占迁移过程；保留 `data` 目录即可延续现有记录。

从 v0.2 更新到 v0.3 只增加小程序会话与微信绑定相关表，不重写现有业务表。更新前仍应保留一致的数据库备份；运行中的 SQLite 使用在线备份，或停止服务后复制完整数据目录。

## 验证

```powershell
npm run build
npm test
.\.venv\Scripts\python.exe -m pytest -q
```

测试覆盖学习业务、账户隔离、CSRF 与会话、恢复校验与回退、并发重复提交、旧数据库迁移和失败回滚。前端另验证账户切换时丢弃旧请求结果、计时分区和原有统计工具函数。详细结果见 [验证记录](VERIFICATION.md)。

小程序在 `miniapp/` 独立执行 `npm test`、`npm run build:mp-weixin` 与 `npm run build:h5`。接口测试覆盖两端会话隔离、微信绑定与解绑、请求重试和并发校验；微信服务调用使用模拟响应，不能替代真实微信与手机验收。

## 设计约定

- 实际学习记录是统计来源；计划用时不会自动计为学习时长。
- 客观题正确率按正确题数 / 总题量加权计算；没有题量时显示空值。
- 主观题用笔记和反馈表达学习结果，不混入客观题正确率。
- 复习间隔为可解释的启发式规则：不会次日再看；模糊保持 1–3 天；掌握逐步增加到 3、7、14、30、60、90、180 天；熟练适当提前增长。并非对个人记忆效果的保证。
- 到期复习先在应用内提醒；没有启动后台消息推送、AI 调用或外部题库采集。
