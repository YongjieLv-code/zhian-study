# 让电脑和手机访问同一个知岸服务

v0.3 提供账户隔离、网页与小程序共用的数据服务，以及微信登录和绑定接口。本目录提供 Docker + Caddy HTTPS 部署配置；当前交付仍运行在本机，并未购买服务器、配置域名或发布公网网站。

## 推荐的初次部署

准备一台安装 Docker Engine / Compose 的 Linux 服务器，并把一个域名的 DNS 指向它。开放 80、443 端口，用于申请证书和 HTTPS 访问。

1. 将项目代码放到服务器，复制 `deploy/.env.example` 为 `deploy/.env`。
2. 填写 `ZHIAN_DOMAIN`；为 `ZHIAN_BOOTSTRAP_TOKEN` 设置随机初始化口令。可以在自己的终端运行 `python3 -c 'import secrets; print(secrets.token_urlsafe(32))'` 生成。
3. 从项目根目录执行：

   ```sh
   docker compose --env-file deploy/.env -f deploy/compose.yaml up -d --build
   ```

4. 打开 `https://你的域名`，填写用户名、密码、初始化口令，创建首个账户。
5. 在本机知岸的“设置 → 导出完整数据”下载 JSON，在新服务的“导入与恢复”预览后恢复。这个流程不会迁移旧登录密码或会话；新服务使用新创建的账户。
6. 手机与电脑打开这个 HTTPS 地址，使用同一个账户登录。保存的记录会在页面打开时每 30 秒刷新，切回页面或点击“立即同步”也会刷新。

默认关闭后续注册。需要为其他人创建独立空间时，再把 `ZHIAN_ALLOW_REGISTRATION` 设为 `true` 并更新服务。首个账户创建完成后，初始化口令不再能认领数据或绕过登录。

## 接入微信小程序

在 `deploy/.env` 设置同一个小程序的 `ZHIAN_WECHAT_APPID` 与 `ZHIAN_WECHAT_SECRET`，重新启动服务。在微信后台添加 HTTPS 合法请求域名，再按 [小程序说明](../miniapp/README.md) 配置前端 AppID 与 `VITE_API_BASE_URL` 并构建。AppSecret 只进入后端环境，不能放入前端变量。

Compose 为应用增加出站网络，以访问微信官方 HTTPS 接口；应用端口仍只在容器网络内使用。Docker 镜像包含网页版与 API；微信包由微信开发者工具上传，本地 `/mini/` 预览不包含在镜像中。

已有知岸账号可以直接使用密码登录小程序；首次绑定微信必须验证已有账号密码。微信主体配置、备案与隐私声明、真机体验及审核发布仍需使用自己的微信开发者账号完成。

## 数据保存与备份

- `study-data` 命名卷保存数据库和自动备份，容器更新不会清空它。
- 应用仅在容器内部网络提供 API；只有 Caddy 对外开放端口。Compose 中信任代理头的配置依赖这一网络隔离，不要再直接公开应用的 8765 端口。
- 自动备份在每次恢复和 v0.1 升级前产生。备份与数据库在同一卷；另行保存导出的 JSON，或使用服务器备份工具复制持久化卷。
- 服务运行时不要只复制 SQLite 主文件而漏掉 WAL。停服务后备份整个卷，或使用 SQLite 自带的在线备份功能。
- JSON 是学习数据备份，不包含账户密码、登录会话或其他账户的数据。完整系统恢复还需要数据库与自动备份文件一起保留。
- 不要执行 `docker compose down -v` 来更新服务；`-v` 会删除持久化卷。普通更新继续使用 `up -d --build`。

## PostgreSQL

少量个人账户可以先使用 SQLite。连接层也支持 PostgreSQL：在 Python 运行环境安装 `psycopg[binary]`，设置 `ZHIAN_DATABASE_URL=postgresql+psycopg://用户:密码@主机/数据库`，再启动服务。镜像当前默认 SQLite；使用 PostgreSQL 时需要在自建镜像中增加驱动。

已有 v0.1 数据表会先备份，再在事务中迁移。SQLite 与 PostgreSQL 之间没有自动搬库任务，可为目标服务创建账户后导出 / 导入每个账户的 JSON。当前自动化和浏览器验收覆盖 Windows + SQLite；这台电脑没有 Docker 运行环境，容器、证书签发与 PostgreSQL 实例尚未实机验证。

## 同步边界

同步依赖同一服务地址、同一账户与网络连接。断网期间没有离线写入队列；保存失败时保留编辑内容并重试。正在运行的专注计时仅存于当前浏览器，保存成学习记录后才同步到其他设备。

复习提交带版本校验，备份恢复带预览后的数据校验，重复提交不会重复累计。同一条普通计划、学习记录或个人目标被多端同时编辑时，以最后成功保存的内容为准。

本版未提供短信 / 邮箱验证、忘记密码自助找回、微信消息推送或小程序发布。已登录用户可以在设置里修改密码，修改后其他登录会话失效。
