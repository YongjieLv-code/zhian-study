# 知岸微信小程序资料包

本目录用于准备微信小程序注册、备案、审核和发布所需的非代码材料。所有涉及个人身份、手机号、邮箱、域名和密钥的内容均保留占位符，不要把真实密码或 AppSecret 写入本目录。

打开 `index.html` 可从浏览器浏览图标、截图和全部文案入口。

## 推荐发布顺序

1. 确认个人或企业主体，注册小程序并取得 AppID。
2. 确认“知岸学习”名称是否可用，填写简介和头像。
3. 选择工具类目，完成备案资料。
4. 部署 HTTPS 服务和正式域名。
5. 配置 AppID、AppSecret、合法请求域名和隐私说明。
6. 用合成账号做真机测试，提交审核。
7. 审核通过后手动发布。

## 发布前必须替换

- `【运营者名称】`
- `【联系邮箱】`
- `【正式 HTTPS 域名】`
- 正式 AppID 和 AppSecret，其中 AppSecret 只配置在后端环境，不写入前端。
- 审核测试账号和密码，只填写到微信审核后台。

## 当前边界

图标、文案和审核截图已经准备好，可直接作为提交候选版本。微信名称是否可用、类目是否需要额外资质、备案材料是否齐全，最终以微信公众平台当日页面和审核结果为准。当前没有真实微信账号、服务器域名、备案号或正式客服联系方式，因此这些项目标记为待补充。
