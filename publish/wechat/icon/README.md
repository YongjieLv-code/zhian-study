# 图标素材

## 主图标

- `zhian-icon.svg`：深绿色主图标，建议用于小程序头像、应用图标和品牌入口。
- `zhian-icon-light.svg`：浅色版本，适合浅色背景、印刷物料或对头像底色有要求的场景。
- `zhian-icon-preview.html`：用于导出 PNG 的等比渲染页，不改动视觉内容。
- `gallery.html`：主图标和浅色版的尺寸预览页。

## 视觉说明

图标沿用现有知岸 favicon 的“山岸、向上路径、暖色圆点”符号。山岸表示稳定的学习积累，向上路径表示持续行动，暖黄色圆点表示阶段性的收获。主色为深绿 `#3D5940`，辅助色为米白 `#EFF2DF`、暖黄 `#E5CD7C`。

## 上传建议

- 优先上传 `zhian-icon-512.png` 或 `zhian-icon.svg` 的导出图。
- 如果后台要求较小尺寸，使用 `zhian-icon-144.png` 或 `zhian-icon-108.png`。
- 上传后以后台预览裁切结果为准，保持图标四周留白，不要在图标上添加名称、网址、二维码或小字。
- 图标上传前不要自行压缩成低清图片；微信后台会在上传后生成不同展示尺寸。
