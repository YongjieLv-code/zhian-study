# 发布前确认清单

## 账号与主体

- [ ] 注册邮箱未绑定过其他微信公众平台账号

- [ ] 服务类目与页面功能一致

- [ ] 公网 HTTPS 服务已部署

- [ ] AppSecret 只配置在服务器环境变量
- [ ] `ZHIAN_ALLOWED_HOSTS` 和 `ZHIAN_ALLOWED_ORIGINS` 已改成正式域名
