# 微信隐私保护指引填写表

在微信公众平台的“用户隐私保护指引”中，按真实处理目的逐项填写。以下内容按知岸 v0.3 的实际能力整理。

## 收集的信息

| 信息类型 | 是否处理 | 使用目的 | 触发方式 |
| --- | --- | --- | --- |
| 账号用户名 | 是 | 创建账号、登录和区分数据归属 | 用户主动填写 |
| 密码 | 是 | 验证登录；服务端只保存不可逆散列 | 用户主动填写 |
| 微信 `openid` | 条件处理 | 使用微信登录或绑定已有账号 | 用户主动选择微信登录 |
| 学习计划 | 是 | 保存用户自己安排的学习任务 | 用户主动填写 |
| 学习记录 | 是 | 记录时长、日期、科目和题目结果 | 用户主动填写 |
| 复习卡片和笔记 | 是 | 保存用户自己整理的复习内容 | 用户主动填写 |
| 备考目标和考试日期 | 是 | 展示个人目标和倒计时 | 用户主动填写 |
| 服务器请求记录 | 是 | 保障服务安全、排查接口故障 | 系统自动产生 |

## 当前不收集的信息

| 信息类型 | 状态 |
| --- | --- |
| 手机号 | 不收集 |
| 精确位置 | 不收集 |
| 通讯录 | 不收集 |
| 相册或摄像头 | 不收集 |
| 麦克风 | 不收集 |
| 银行卡或支付信息 | 不收集 |
| 微信头像和昵称 | 不收集 |
| 微信好友关系 | 不收集 |
| 广告标识符 | 不收集 |

## 需要准备的用户说明

建议在登录页底部或登录确认弹窗中提供：

> 登录即表示你已阅读并同意《隐私政策》。我们会保存你主动填写的账号和学习数据，用于记录、同步和统计。你可以随时退出登录、取消微信绑定或联系我们删除账号数据。

如果使用微信登录，还应在上线前按微信隐私保护指引完成：

- 在微信后台配置隐私保护指引。
- 在首次触发微信登录前向用户展示处理目的。
- 用户拒绝微信授权时，仍可使用用户名和密码登录。
- 在隐私政策中提供运营者、联系方式和数据删除方式。

## 需要后端确认

- 服务端日志不记录明文密码、登录令牌、AppSecret 或微信 `session_key`。
- HTTPS 部署启用 Secure Cookie。
- 备份文件不与公开目录直接绑定。
- 账号注销后，删除该账号的会话、微信绑定和个人业务数据，除非法律要求保留。
