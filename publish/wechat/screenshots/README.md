# 审核截图

这些截图来自隔离测试数据库，账号名为 `mini_verify`，数据为合成内容。截图尺寸统一为 390 × 844，适合作为审核材料或产品说明素材。

| 文件 | 页面 |
| --- | --- |
| `01-today.png` | 今日概览 |
| `02-plans.png` | 学习计划 |
| `03-reviews.png` | 复习卡片 |
| `04-stats.png` | 统计复盘 |
| `05-mine.png` | 我的知岸 |
| `06-login.png` | 登录页面 |

截图中有意保留了测试账号、计划、学习记录和复习卡片。提交审核时不要替换成真实用户的姓名、手机号、邮箱或密码。
